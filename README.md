# Legacy — Propriedade Intelectual

Site estático em português baseado no conteúdo e na disposição das seções de https://alannediasdesigner.wixstudio.com/my-site-4.

## Executar

Sirva a pasta `dist` com qualquer servidor HTTP. Exemplo: `npx serve dist`.
