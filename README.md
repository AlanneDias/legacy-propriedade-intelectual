# Legacy — Propriedade Intelectual

Site estático em português baseado no conteúdo e na disposição das seções de https://alannediasdesigner.wixstudio.com/my-site-4.

## Executar

Sirva a pasta `dist` com qualquer servidor HTTP. Exemplo: `npx serve dist`.

## Conteúdo

HTML, CSS e JavaScript sem etapa de compilação. Imagens fornecidas pela responsável pelo projeto ou extraídas da referência indicada. A paleta segue os arquivos fornecidos. Fontes carregadas do Google Fonts com alternativas locais.

O formulário prepara uma mensagem no aplicativo de email do visitante; não armazena dados nem afirma que a mensagem foi enviada. Conectar um serviço de envio é necessário para receber submissões diretamente pela página.

O conteúdo de Registro de Desenho Industrial foi preservado como na referência, onde repete a descrição de Registro de Software. Deve ser revisado pela responsável antes de divulgação pública.
